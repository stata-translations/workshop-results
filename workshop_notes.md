## Some notes from the workshop.
Held sucessfully on 10/07/2026 around 10 attendees (statisticians) + 3 ARC and me presenting.

 - Lot's of setup issues getting to grips with the different user interfaces in Claude (code vs. chat) installing the plugin. But I don't think any worse than typical issues we get at carpentries. We got most people up and running in the first half hour.

 - We managed to use different models and packages (13 pre workshop surveys 9 post workshop)

 - We observed differences in different people's translations but nothing outrageous.

 - There was one significant bug where the pseudo code to R step greatly simplified the code by ignoring most of the data.

 - There was one instance where Claude correctly identified that there was an existing R libary, so don't translate (but did suggest translation to python.)
 
 - One participant used fable and rapidly ran out of credits.

 - Lots of discussion about next steps and how to validate the translated code beyond the existing steps. For the artbin package subtle errors in sample size calculation may be hard to spot but could have significant implications if a clinical trial sample required sample size was miscalculated.
